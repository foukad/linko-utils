# linko-utils

A small open-source toolkit containing simple utilities for networking, Java experimentation, and DevOps automation.

## Included Utilities

- **NetworkUtils.java** – Java class with port validation and a banner printer, useful for learning and prototyping networking concepts.
- **ping-check.sh** – Bash script that pings a hostname three times and reports the result, handy for quick connectivity checks.
- **docs/overview.md** – Documentation covering the purpose of the repo and how to use each utility.

## Purpose

This repository is intended for:

- **Experimentation** – Try out networking and Java concepts in a low-stakes environment.
- **Learning** – Each utility is small, well-commented, and easy to follow.
- **Reusable components** – Copy what you need into your own projects.
